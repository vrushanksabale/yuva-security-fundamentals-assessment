# Yuva Internship – Security Fundamentals Assessment

## Overview

This repository contains my Security Fundamentals Assessment for the Yuva Internship. The assessment focuses on fundamental Security Operations Center (SOC) concepts, cybersecurity threats, security monitoring, and incident response.

## Objectives

* Understand the role and responsibilities of a SOC Analyst.
* Study common cybersecurity threats and Indicators of Compromise (IOCs).
* Learn security monitoring and log analysis.
* Understand SIEM, IDS, IPS, and EDR tools.
* Study the incident response lifecycle.
* Identify SOC challenges and recommend security best practices.

## Topics Covered

1. Introduction to Security Operations Centers
2. SOC Analyst Responsibilities
3. Cybersecurity Threats and IOCs
4. Security Monitoring and Log Analysis
5. SIEM, IDS, IPS, and EDR
6. Incident Response Lifecycle
7. Practical Suspicious Login Investigation
8. SOC Challenges and Security Recommendations

## Practical Learning

The assessment includes a fictional suspicious-login investigation demonstrating how security analysts can review authentication logs, investigate alerts, correlate evidence, and recommend appropriate defensive actions.

All practical examples are intended for educational and defensive cybersecurity learning.
